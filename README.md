One sentence, 170 characters, explaining the modern internet to a time traveler arriving from the year 1800 — built only from things they already know (a library, a post office, a market) joined by one comparison, invisible roads. A judge model compares the sentences two at a time and the best ranked wins.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

## The sentence

> Imagine every library, post office, and market in the world joined by invisible roads, so any letter, book, or picture can reach anyone, anywhere, in the blink of an eye.
